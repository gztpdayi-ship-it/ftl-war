# FTL WAR v0.10

Bu sürümde oluşturduğumuz FTL WAR görsel konsepti oyunun içine uygulandı.

## Ana değişiklik
- Kaynak alanı ekranı artık ayrıntılı, resimli bir FTL WAR dünyası kullanır.
- Merkez köy, dağlar, ormanlar, nehirler, tarlalar, maden bölgeleri ve yollar aynı büyük oyun arazisi üzerinde görünür.
- 18 kaynak alanı mavi dairesel seviye rozetleri şeklinde haritanın üzerine yerleştirildi.
- Rozete tıklamak mevcut kaynak yükseltme fonksiyonunu çalıştırır.
- Kaynak seviyesi değiştikçe rozet üzerindeki sayı otomatik güncellenir.
- Görseller `assets` klasöründedir ve GitHub Pages üzerinde çalışır.

## Görsel dosyaları
- `assets/ftl-war-resource-world.jpg` — oyunda kullanılan kaynak dünyası
- `assets/ftl-war-ui-reference.jpg` — oluşturduğumuz tam FTL WAR arayüz konsepti

- Sunucu hızı: x10.000.000
