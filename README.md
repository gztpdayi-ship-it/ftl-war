# FTL WAR

Tarayıcı tabanlı PvP strateji oyunu prototipi.

- Genel hız: x10.000.000
- Dünya Harikası: 1x
- Merkez köy kaynak alanları: maksimum 30
- Diğer köyler: maksimum 20
- Kabileler: Romalılar, Cermenler, Türkler, Vikingler, Galyalılar
- Altın ve MultiHunter sistemi sonraki backend aşamasında eklenecek.

## Yerel çalıştırma
`index.html` dosyasını tarayıcıda açabilir veya herhangi bir statik hosting servisine yükleyebilirsin.
